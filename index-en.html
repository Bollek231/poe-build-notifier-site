PoE Build Notifier is a private, non-commercial Discord bot. It uses publicly available YouTube information to discover recent Path of Exile 1 build guides and share them in a designated Discord channel.

Open-source code

You can download the Python source code as a ZIP file and run it on your computer or server. The archive includes example configuration and automated tests. It does not contain any real tokens, API keys, private .env files, or SQLite databases.

GitHub Pages only hosts this website and downloads. It does not host the running Discord bot. You need your own machine or server, Discord bot token, and YouTube Data API key.

How do we use YouTube?

The bot uses YouTube Data API v3 to retrieve public video titles, descriptions, publication dates, and channel information. It links to original videos rather than downloading or re-uploading them.

No Google or YouTube account login is required. This project is not affiliated with Google, YouTube, Discord, or Grinding Gear Games.
