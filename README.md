# PoE Build Notifier — strona projektu

Publiczna strona informacyjna niekomercyjnego bota Discord używającego YouTube Data API v3 do wyszukiwania poradników do Path of Exile 1.

## Dokumenty
- [Strona główna](index.html)
- [Polityka prywatności](privacy.html)
- [Warunki korzystania](terms.html)

## Publikacja za pomocą GitHub Pages
W repozytorium otwórz **Settings → Pages**, wybierz **Build and deployment → Source: Deploy from a branch**, ustaw **Branch: main**, **Folder: /(root)** i kliknij **Save**.

Po włączeniu Pages i zakończeniu publikacji sprawdź:
- https://bollek231.github.io/poe-build-notifier-site/
- https://bollek231.github.io/poe-build-notifier-site/privacy.html
- https://bollek231.github.io/poe-build-notifier-site/terms.html

## Ważne
Strona nie jest dowodem pełnej zgodności bota z zasadami YouTube API. Przed formularzem kontroli sprawdź rzeczywistą retencję metadanych YouTube w bazie SQLite oraz wymagania dotyczące zgody i dostępu do polityki prywatności. Nie publikuj pliku .env, tokenu Discorda, klucza YouTube API ani prywatnego klucza konta Google Cloud.
