# PoE Build Notifier — strona projektu

Publiczna strona informacyjna niekomercyjnego bota Discord wykorzystującego YouTube Data API v3 do wyszukiwania poradników do Path of Exile 1.

## Dokumenty i linki

- 🌐 **[Strona główna](https://bollek231.github.io/poe-build-notifier-site/index.html)**
- 🔒 **[Polityka prywatności](https://bollek231.github.io/poe-build-notifier-site/privacy.html)**
- 📄 **[Warunki korzystania](https://bollek231.github.io/poe-build-notifier-site/terms.html)**

## O projekcie

Bot automatycznie wyszukuje nowe poradniki buildów Path of Exile 1, filtruje materiały, wykrywa duplikaty i zamieszcza na Discordzie odnośniki do oryginalnych filmów YouTube. Może dołączać przyciski do Path of Building i Maxroll, jeśli twórcy podali odpowiednie adresy.

Projekt nie jest powiązany z YouTube, Google, Discord ani Grinding Gear Games.
