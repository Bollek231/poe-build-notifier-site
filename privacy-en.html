Privacy Policy

Published: November 12, 2026 • Applies to the “PoE Build Notifier” Discord bot.

This policy describes how the independent Discord bot “PoE Build Notifier” handles information. The project is operated by the owner of the GitHub account Bollek231. Contact: GitHub Issues. Issues are public. Do not post sensitive information there; request a private contact method first if needed.

1. YouTube integration

The app uses YouTube API Services, including YouTube Data API v3, to search for and display publicly available video information. Use of these services is also subject to the YouTube Terms of Service and Google Privacy Policy.

2. What data is processed?

  • Public YouTube information: video IDs, titles, descriptions, channel names, thumbnails, publication dates, URLs, and links provided by video creators.
  • Technical information: search phrases, timestamps, API usage counters, and build similarity data used to reduce duplicate notifications.
  • Discord commands: the bot reads commands in the configured channel to the extent necessary to perform them. These messages may be visible to other users with access to the channel.

3. Purposes of processing

Data is used to find new Path of Exile 1 builds, filter outdated content, avoid duplicates, post Discord notifications, and manage API usage. The project does not sell data or use it for advertising-based profiling.

4. Data storage

The bot stores data obtained from YouTube Data API locally in the administrator's SQLite database, including video IDs, titles, publication dates, links, and information used for duplicate detection. The current version clears locally stored YouTube metadata after 7 days. The bot does not download video files.

Notifications already sent to Discord remain in the channel. The bot does not automatically delete them after 7 days or modify previously posted messages. Such messages may continue to contain YouTube information even after it has been removed from the local database. Discord retention depends on that platform and the server settings; server administrators may delete messages manually.

To manage voluntary acceptance of the rules for administrative commands, the bot stores a Discord user ID, server ID, date of acceptance, and the version of the terms accepted. That record is kept until acceptance is withdrawn or an administrator deletes it. The bot does not grant Discord roles and does not require acceptance to receive automatic channel notifications.

The bot does not collect YouTube passwords, sign users in via Google OAuth, or access their private videos.

4a. Acceptance and withdrawal for commands

Anyone using administrative bot commands should first read this policy and the Terms of Use. Acceptance can be recorded with the “I accept the terms” button in pPrivacy or with pAgree. To withdraw, use the “Withdraw consent” button or pRevoke.

Acceptance does not grant roles or change channel permissions. Automatic video notifications are visible according to ordinary Discord permissions, including to users who have not run bot commands. Therefore, acceptance before using commands does not represent consent from all recipients of notifications.

5. Data sharing

Search requests are sent to Google/YouTube, while notifications about videos are posted to a designated Discord channel. Google, Discord, and GitHub may process technical data according to their own policies. The bot does not re-upload video files.

6. Cookies and analytics

This static website does not use its own advertising trackers or analytics scripts. GitHub Pages may process technical traffic data under its own terms.

7. Data-related requests

Requests for explanations or removal of information controlled by this bot can be made through the project repository. Do not publish personal information there. The operator may delete relevant locally stored records where technically possible and appropriate.

7a. Additional data and settings

The bot may store YouTube channel identifiers selected for blocklists or allowlists, advanced build filters, and local configuration in SQLite. These channel rules and filters remain until an administrator changes or removes them.

To complete guide buttons, the bot keeps identifiers for its own Discord messages, YouTube video identifiers, and discovered external guide URLs. This tracking data is deleted from the local database within 7 days. The bot may edit buttons on its previously posted messages, but does not delete Discord messages.

External PoB, Maxroll, and Mobalytics links are checked using limited HTTPS requests. These websites may receive technical connection information, such as the bot server's IP address. The bot never sends API tokens to guide sites and does not follow redirects.

The bot can create private snapshots of its complete local SQLite database (a maximum of 7 recent backup files by default). These snapshots may contain Discord identifiers, historical YouTube metadata, and settings, and can preserve records beyond the 7-day retention of the active database. The backup feature does not upload snapshots to GitHub or other services. The administrator is responsible for secure storage and deletion of backups.

Technical alerts may be posted to a Discord channel selected by the administrator. The bot also checks a public GitHub VERSION file for releases, without transmitting secret tokens or automatically installing code updates.

8. Updates

This policy may change as the application evolves. The latest version is published on this page.

Note: the bot currently reads public information using an API key; it does not use Google OAuth for end-user login. This policy should be revised if access methods or data handling change.
