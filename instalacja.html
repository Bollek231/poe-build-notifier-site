Instalacja bota krok po kroku

Bot działa na Twoim komputerze lub serwerze. GitHub Pages publikuje jedynie tę stronę, dokumentację i pliki do pobrania — nie uruchamia bota na Discordzie.

Pobierz bota ZIPPrzeglądaj kod na GitHubie

1. Pobierz i rozpakuj pliki

Pobierz ZIP i wypakuj go np. do D:\PoE-Bot. W tym folderze powinny znaleźć się main.py, storage.py, features.py, requirements.txt i .env.example.

2. Przygotuj Pythona

Zainstaluj Python 3.11 lub nowszy. Otwórz CMD w folderze bota i wykonaj:

cd /d D:\PoE-Bot
py -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt

3. Utwórz własnego bota Discord

W Discord Developer Portal utwórz aplikację i bota. W zakładce Bot włącz Message Content Intent. Zaproś bota na swój serwer z prawem czytania i wysyłania wiadomości, wstawiania linków i używania osadzonych komponentów. Skopiuj identyfikator kanału z trybu deweloperskiego.

Nie udostępniaj tokenu Discorda.

4. Przygotuj klucz YouTube Data API v3

W Google Cloud Console wybierz projekt, otwórz Interfejsy API i usługi → Biblioteka, włącz YouTube Data API v3, a następnie w sekcji Dane logowania utwórz klucz API. Dla bezpieczeństwa ogranicz klucz do YouTube Data API v3. Limity sprawdzisz w konsoli Google.

5. Skonfiguruj plik .env

copy .env.example .env
notepad .env

Wpisz własne wartości w pliku .env (poniżej są wyłącznie przykłady pól, nie prawdziwe klucze):

DISCORD_TOKEN=TU_WLASNY_TOKEN
DISCORD_CHANNEL_ID=TU_ID_KANALU
YOUTUBE_API_KEY=TU_WLASNY_KLUCZ
CHECK_INTERVAL_HOURS=2
SEND_DELAY_SECONDS=3
MAX_VIDEO_AGE_HOURS=24
YOUTUBE_CACHE_DAYS=7
DAILY_DIGEST_ENABLED=true
DAILY_DIGEST_TIME=20:00
TARGET_LEAGUE=3.30
Bezpieczeństwo: nie przesyłaj na GitHuba pliku .env, bazy .sqlite3, plików JSON z kont Google ani tokenów. Repozytorium zawiera tylko przykładową konfigurację.

6. Uruchom i przetestuj

python main.py

Na Discordzie zacznij od pPrivacy i pAgree, potem użyj pHealth, pSettings oraz pLeague. Zobacz pełny opis komend.

Aktualizowanie istniejącej instalacji

Zatrzymaj bota przez Ctrl + C, zrób kopię folderu i zastąp tylko main.py, storage.py, features.py, enhancements.py, services.py, backups.py, VERSION oraz requirements.txt. Zachowaj własny .env, search_config.json i poe330_seen.sqlite3. Następnie uruchom:

python -m pip install -r requirements.txt
python main.py

Nowe pliki i ustawienia w v0.5.1

Podczas aktualizacji skopiuj też nowe pliki enhancements.py, services.py, backups.py i VERSION. Zachowaj dotychczasowe .env, search_config.json oraz bazę SQLite. Nie uruchamiaj dwóch instancji bota z tym samym tokenem.

# Opcjonalne wpisy do prywatnego .env
DAILY_SEARCH_BUDGET=96
RESERVED_SEARCHES=24

ALERT_CHANNEL_ID=0 wyłącza alerty na Discordzie; można wpisać ID prywatnego kanału administracyjnego. Bez tej zmiennej bot używa kanału buildów. Na Railway/VPS ustaw BACKUP_DIR=/data/backups oraz DB_PATH=/data/poe330_seen.sqlite3 na trwałym dysku. Kopie zawierają ID użytkowników i lokalne dane, więc nie publikuj ich na GitHubie.

Nowe komendy: pWhitelist, pFilters, pRefreshLinks, pBackup, pVersion oraz komendy list kanałów. Szczegóły: Działanie i komendy.

Typowe problemy

  • HTTP 429 — wykorzystano limit wyszukiwań YouTube; bot pokaże reset i wstrzyma zapytania.
  • Nie reaguje na komendy — sprawdź Message Content Intent, kanał i uprawnienia „Zarządzanie serwerem”.
  • Brak strefy czasowej — uruchom python -m pip install tzdata.
  • Brak nowych filmów — bot filtruje filmy starsze niż 24h, inne ligi, PoE 2 i duplikaty.

Projekt jest niekomercyjny i nie jest powiązany z Google, YouTube, Discord ani Grinding Gear Games.
