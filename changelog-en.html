Patch Notes v0.6.1

New features and changes in each PoE Build Notifier release.

PoE Build Notifier v0.6.1

November 13, 2026

Languages and settings

  • New pLanguage command with a Discord Polski / English picker, plus pLanguage pl and pLanguage en.
  • English translations for command replies, alerts and build notification labels.
  • pSettings now provides interactive editing via forms, dropdowns and toggles.
  • Change scan intervals, digest time, result counts, YouTube search budget, message delays, video age and GitHub version-check intervals.
  • Input and permission validation, SQLite persistence and updates applied without a restart.

PoE Build Notifier v0.6.0

November 13, 2026

Path of Exile 2

  • pGame poe1 / pGame poe2 — switch the game used for build discovery.
  • Separate PoE 1 and PoE 2 patch targets and filters stored in SQLite.
  • Dedicated PoE 2 1.0 search phrases with older-patch exclusions.
  • Independent check that videos were published within the past 24 hours.
  • Support for Mobalytics PoE 2 links (/poe-2/).

PoE Build Notifier v0.5.2

November 13, 2026

Website redesign

  • Dark-fantasy GitHub Pages redesign with feature cards and a Discord command preview.
  • Animated particles, emblem and cursor-following spotlight.
  • ☀️/🌙 light/dark themes, responsive layout and accessibility controls.
  • Consistent appearance throughout the Polish and English documentation.

PoE Build Notifier v0.5.1

November 13, 2026

Discovery and reliability

  • Smarter local YouTube API budget and search query rotation.
  • Channel allow/block lists and filters for skills, classes, ascendancies and game modes.
  • PoB, Maxroll and Mobalytics URL validation and automatic button completion in Discord posts.
  • Technical/reconnection alerts and private SQLite backups.
  • pVersion and GitHub update notifications.
