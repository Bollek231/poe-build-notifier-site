PoE Build Notifier v0.5.1

November 13, 2026

New features

  • Smart YouTube API quota allocation: distribute locally estimated daily searches over scheduled scans, rotate phrases, and reserve manual searches.
  • Channel blocklists and allowlists: pBlockChannel, pAllowChannel, pUnlistChannel, pChannelRules, pWhitelist on/off.
  • Advanced build filters: skill, ascendancy, base class, SSF/HC/SC and build stage; pFilters and pFilter.
  • External link validation: strict HTTPS domains for PoB, Maxroll and Mobalytics; transient failures do not remove buttons.
  • Automatic button completion: check new description links every 6 hours and edit existing Discord message buttons; only posts created by v0.5.1 and tracked for up to 7 days; pRefreshLinks.
  • Operational alerts: startup, recovered connection, errors and update notifications with cooldowns.
  • Automatic backups: daily private SQLite snapshots with rotation and pBackup.
  • GitHub release checks: pVersion, periodic public VERSION checks and update notifications — never automatic installations.

Retains all v0.5.0 features, the 24-hour video age limit, two-hour scans, three-second posting delay, 429 protection, league changes, daily digest, and no automatic deletion of Discord messages. Includes additive SQLite migrations and 46 offline tests.

PoE Build Notifier v0.5.0

November 13, 2026

New in this update

  • Introduced project versioning: PoE Build Notifier v0.5.0.
  • Added bilingual Patch Notes / Lista zmian pages with 🇵🇱 / 🇬🇧 switching.
  • Added a repository-level CHANGELOG.md.
  • Made version numbers consistent across the site and README files.

Features present in the baseline

  • Automated Path of Exile 1 searches every two hours, a 24-hour video age filter and selectable leagues.
  • pLeague, pScan, pSearch, pLimit, pHealth, pSettings, pBuilds and pDigest commands.
  • Path of Building, Maxroll and Mobalytics buttons for matching links in video descriptions.
  • Daily digest at 8:00 PM Warsaw time, plus manual scanning.
  • YouTube quota pause, duplicate filtering and 3-second delays between posted notifications.
  • Seven-day cleanup of locally cached YouTube metadata without deleting Discord messages.
  • Sanitized public source code on GitHub and bilingual documentation.
