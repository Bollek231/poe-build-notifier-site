Patch Notes v0.6.4d

New features and changes in each PoE Build Notifier release.

PoE Build Notifier v0.6.4d

November 13, 2026

Discord notification redesign

  • Purple build embeds and gold farming embeds with clearer headers, fields, thumbnails and concise footers.
  • pEmbedStyle compact and pEmbedStyle expanded select the layout for new notifications; pEmbedStyle status displays the current option. Expanded is the default.
  • Contextual Save, YouTube, PoB, Maxroll, Mobalytics and PoE Planner buttons. The duplicate raw YouTube URL above notifications was removed.
  • Cleaned up technical labels and enabled saving from dedicated farming channels. Previously posted messages are unchanged.

PoE Build Notifier v0.6.4c

November 13, 2026

PoE Planner buttons

  • Currency-farming notifications now include a PoE Planner button whenever the YouTube description includes a link to https://poeplanner.com or https://www.poeplanner.com.
  • Added safe domain validation and PoE Planner support when refreshing buttons in previously posted messages.

PoE Build Notifier v0.6.4b

November 13, 2026

Optional video count for manual scanning

  • pScan and pFarmScan accept a new-video limit, e.g. pScan 1, pScan 2, pFarmScan 1, pFarmScan 2.
  • Without a count, both retain their full manual scan behavior. Valid range: 1–25 videos. The number caps posted or queued matches, not YouTube API queries.
  • The cap also applies during quiet hours, and the scan summary reports queued videos.

PoE Build Notifier v0.6.4

November 13, 2026

Currency farming strategies

  • Added pFarmScan and pFarmSearch TOPIC for currency farming guides in PoE 1 and PoE 2.
  • pFarmTopics lists supported strategies and pFarmRecent shows recently discovered videos.
  • pFarmAuto on/off/status controls opt-in monitoring. When enabled, it uses at most one additional query per interval within the existing shared YouTube budget.
  • New patch and freshness filters keep farming videos separate from build history; quiet-hours strategies are delivered in a digest.
  • Optional dedicated Discord channel with FARM_CHANNEL_ID in the private .env.

PoE Build Notifier v0.6.3

November 13, 2026

Windows launcher and automatic updates

  • Added a desktop launcher with start/stop controls and live logs, without manually typing CMD commands.
  • On startup the launcher checks GitHub, downloads and automatically installs a newer bot version.
  • Only program files are replaced; private .env, SQLite data and user settings stay intact.
  • Added rollback of program files on install failure, .bat and .vbs shortcuts, and automated ZIP packaging.

PoE Build Notifier v0.6.2b

November 13, 2026

Choose a translation provider

  • New MyMemory option for English title translations, without an API key or billing.
  • Switch to Google Cloud Translation with your own API key via pTranslateTitles google, or choose MyMemory with pTranslateTitles mymemory.
  • New provider setting in pSettings, saved to SQLite.
  • Local language detection for MyMemory, separate translation caches, bounded requests and safe fallback to original titles.
  • pVersion now accepts letter-suffixed releases such as 0.6.2b.

PoE Build Notifier v0.6.2

November 13, 2026

Community tools and title translations

  • New pSetup menu for game, patch, bot language and scan interval.
  • Interactive pHelp command categories and examples.
  • pQuietHours queues recent guides and posts one digest after the quiet period.
  • pPause and pResume suspend scheduled scans without preventing manual searches.
  • pSaved adds a Save button and private, user-controlled video bookmarks.
  • pTrending compares YouTube view growth between observations.
  • pTranslateTitles optionally translates titles to English via Google Cloud Translation, with original titles, caching and request limits.

PoE Build Notifier v0.6.1

Languages and settings

  • New pLanguage command with a Discord Polski / English picker, plus pLanguage pl and pLanguage en.
