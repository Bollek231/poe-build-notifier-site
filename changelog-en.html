PoE Build Notifier v0.5.0

November 13, 2026

New in this update

  • Introduced project versioning: PoE Build Notifier v0.5.0.
  • Added bilingual Patch Notes / Lista zmian pages with 🇵🇱 / 🇬🇧 switching.
  • Added a repository-level CHANGELOG.md.
  • Made version numbers consistent across the site and README files.

Features present in the baseline

  • Automated Path of Exile 1 searches every two hours, a 24-hour video age filter and selectable leagues.
  • pLeague, pScan, pSearch, pLimit, pHealth, pSettings, pBuilds and pDigest commands.
  • Path of Building, Maxroll and Mobalytics buttons for matching links in video descriptions.
  • Daily digest at 8:00 PM Warsaw time, plus manual scanning.
  • YouTube quota pause, duplicate filtering and 3-second delays between posted notifications.
  • Seven-day cleanup of locally cached YouTube metadata without deleting Discord messages.
  • Sanitized public source code on GitHub and bilingual documentation.
