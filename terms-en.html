Terms of Use

Effective November 12, 2026.

1. Description of the service

PoE Build Notifier is a non-commercial Discord bot that discovers and shares links to publicly available Path of Exile 1 build guides. It uses YouTube Data API v3. This is an independent project with no official affiliation to Google, YouTube, Discord, or Grinding Gear Games.

2. Use of YouTube

Users of YouTube API-based features must also comply with the YouTube Terms of Service. The Google Privacy Policy also applies to relevant Google services.

3. Features

  • Automated and manual video searches.
  • Filtering videos by age, league, and content similarity.
  • Sharing video titles, publication dates, creators, and links to original YouTube videos.
  • Optional buttons to external Path of Building, Maxroll, and Mobalytics guides where relevant links are provided.

3a. Additional capabilities

The bot offers search budget management, YouTube channel blocklists and allowlists, advanced build filters, external guide URL checks, updates to buttons on existing Discord messages, technical alerts, private SQLite backups, and GitHub version checks. Limited HTTPS requests may be sent to supported guide providers. The bot does not install code updates or automatically remove previously posted Discord messages.

4. Limitations

Automated filters can make mistakes. Availability depends on YouTube, Discord, and API quotas. The operator may change, suspend, or update the application's features.

5. Third-party content

Copyright and other rights in videos and guides belong to their respective creators. The bot does not authorize copying videos and does not guarantee the accuracy of any guide. Links to third-party sites are subject to their providers' rules.

6. Privacy and command acceptance

Information about data handling can be found in the Privacy Policy. Users of administrative bot commands can accept the terms using pPrivacy and its “I accept the terms” button, or by entering pAgree. Acceptance can be withdrawn with pRevoke or the “Withdraw consent” button. Acceptance does not grant roles or change access to the Discord channel.

Links and notifications posted to Discord remain in the channel without automatic removal. The bot clears locally cached YouTube metadata from SQLite after 7 days, but does not delete or edit old Discord messages. Server administrators may manage messages independently. Do not share passwords or API keys in Discord messages.
