Install the bot step by step

The bot runs on your computer or server. GitHub Pages only hosts this website, documentation, and downloads — it cannot run the bot for you.

Download bot ZIPBrowse source code

1. Download and extract

Download the ZIP and extract it into a folder such as D:\PoE-Bot. The extracted folder should contain main.py, storage.py, features.py, requirements.txt and .env.example.

2. Set up Python

Install Python 3.11 or later. Open Windows Command Prompt (CMD) in your bot folder and run:

cd /d D:\PoE-Bot
py -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt

3. Create your Discord bot

Visit the Discord Developer Portal, create an application and a bot, then enable Message Content Intent in the Bot settings. Invite the bot to your server with permissions to view and send messages, embed links, and use message components. Enable Discord Developer Mode to copy the target channel ID.

Never disclose your Discord bot token.

4. Create a YouTube Data API v3 key

Open the Google Cloud Console, select or create a project, go to APIs & Services → Library, enable YouTube Data API v3, then go to Credentials to create an API key. Restrict the key to the YouTube Data API v3 where practical. You can check usage limits in Google Cloud.

5. Configure .env

copy .env.example .env
notepad .env

Enter your own values into .env. The following values are placeholders, not real credentials:

DISCORD_TOKEN=YOUR_OWN_TOKEN
DISCORD_CHANNEL_ID=YOUR_CHANNEL_ID
YOUTUBE_API_KEY=YOUR_OWN_API_KEY
CHECK_INTERVAL_HOURS=2
SEND_DELAY_SECONDS=3
MAX_VIDEO_AGE_HOURS=24
YOUTUBE_CACHE_DAYS=7
DAILY_DIGEST_ENABLED=true
DAILY_DIGEST_TIME=20:00
TARGET_LEAGUE=3.30
Security: never commit your actual .env, .sqlite3 database, Google service-account JSON files, or secret tokens. This repository contains example settings only.

6. Start and test

python main.py

On Discord, begin with pPrivacy and pAgree, then check pHealth, pSettings, and pLeague. See all available commands.

Updating an existing installation

Stop the bot with Ctrl + C and back up its folder. Replace main.py, storage.py, features.py, enhancements.py, services.py, backups.py, VERSION and requirements.txt. Keep your own .env, search_config.json and poe330_seen.sqlite3 files. Then run:

python -m pip install -r requirements.txt
python main.py

Updating an existing installation

Stop the bot and back up its folder and SQLite database. Copy the Python modules from the current archive, including game_modes.py, localization.py and runtime_settings.py, along with requirements.txt and VERSION. Keep your private .env, custom search_config.json and SQLite database. Never run two instances with the same token.

# Optional entries in your private .env
DAILY_SEARCH_BUDGET=96
RESERVED_SEARCHES=24
ALERT_CHANNEL_ID=0
CHECK_EXTERNAL_LINKS=true
LINK_REFRESH_INTERVAL_HOURS=6
MAX_LINK_REFRESH_PER_RUN=10
BACKUP_DIR=backups
BACKUP_KEEP_DAYS=7
VERSION_CHECK_ENABLED=true

ALERT_CHANNEL_ID=0 disables Discord alerts. Set this to a private admin channel ID instead; if unset, the build channel is used. For Railway/VPS, store BACKUP_DIR=/data/backups and DB_PATH=/data/poe330_seen.sqlite3 on a persistent volume. Backups contain local database and Discord IDs and must remain private.

New commands: pWhitelist, pFilters, pRefreshLinks, pBackup, pVersion, and channel list commands. See Features and commands.

Troubleshooting

  • HTTP 429: your YouTube search quota has been exhausted; the bot displays the next expected reset and pauses searches.
  • Commands do not respond: verify Message Content Intent, channel configuration, and the Manage Server permission.
  • Time zone not found: run python -m pip install tzdata.
  • No new videos: the bot excludes videos older than 24 hours, previous leagues, Path of Exile 2 content, and duplicates.
