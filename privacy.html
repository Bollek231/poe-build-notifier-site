Polityka prywatności

Data publikacji: 12 listopada 2026 r. • Dotyczy bota Discord „PoE Build Notifier”.

Ta polityka wyjaśnia, jak niezależny bot Discord „PoE Build Notifier” korzysta z danych. Operatorem projektu jest właściciel konta GitHub Bollek231. Kontakt: GitHub Issues. Zgłoszenia są publiczne, dlatego nie należy w nich podawać danych wrażliwych; w takiej sytuacji poproś najpierw o prywatny sposób kontaktu.

1. Integracja z YouTube

Aplikacja korzysta z YouTube API Services, w tym YouTube Data API v3, aby wyszukiwać i prezentować publiczne dane o filmach. Korzystanie z usług podlega również Warunkom korzystania z YouTube i Polityce prywatności Google.

2. Jakie dane są przetwarzane?

  • Publiczne informacje z YouTube: identyfikatory filmów, tytuły, opisy, nazwy kanałów, miniatury, daty publikacji, adresy URL i linki podane przez twórców.
  • Dane techniczne: zapytania wyszukiwania, znaczniki czasu, liczniki API i informacje o podobieństwie buildów potrzebne do ograniczania duplikatów.
  • Komendy Discord: bot odczytuje polecenia na skonfigurowanym kanale w zakresie niezbędnym do ich wykonania. Wiadomości mogą być widoczne dla użytkowników tego kanału.

3. Cele przetwarzania

Dane są używane do wyszukiwania nowych buildów Path of Exile 1, filtrowania nieaktualnych materiałów, zapobiegania duplikatom, publikowania powiadomień na Discordzie i kontrolowania limitów zapytań. Projekt nie sprzedaje danych i nie wykorzystuje ich do profilowania reklamowego.

4. Przechowywanie danych

Metadane filmów, identyfikatory i informacje o zapytaniach mogą być przechowywane lokalnie w bazie SQLite na urządzeniu administratora. W obecnej implementacji część rekordów nie jest automatycznie usuwana po stałym czasie i może wymagać ręcznej aktualizacji lub usunięcia. Operator powinien dostosować okres przechowywania i aktualizację metadanych do obowiązujących zasad YouTube API. Sama publikacja tej polityki nie potwierdza spełnienia wymagań retencji YouTube.

Bot nie pobiera haseł użytkowników YouTube, nie korzysta z autoryzacji OAuth w ich imieniu ani nie uzyskuje dostępu do prywatnych filmów i playlist.

5. Udostępnianie informacji

Zapytania są wysyłane do Google/YouTube, a powiadomienia o filmach trafiają na wybrany kanał Discord. Dostawcy usług Google, Discord i GitHub przetwarzają dane zgodnie ze swoimi zasadami. Bot nie przesyła ponownie plików wideo.

6. Pliki cookie i analityka

Strona jest statyczna i nie zawiera własnych trackerów reklamowych ani analitycznych. GitHub Pages może przetwarzać techniczne dane o ruchu zgodnie z własnymi zasadami.

7. Prośby dotyczące danych

Wnioski o wyjaśnienie działania bota lub o usunięcie danych pod jego kontrolą można zgłaszać przez repozytorium projektu. Nie publikuj tam danych osobowych. Operator może usunąć odpowiednie rekordy przechowywane lokalnie, jeśli jest to technicznie możliwe i uzasadnione.

8. Zmiany polityki

Polityka może być aktualizowana wraz ze zmianami działania aplikacji. Aktualną wersję można znaleźć na tej stronie.

Uwaga: bot obecnie odczytuje publiczne dane przez klucz API, bez logowania użytkowników przez Google OAuth. Jeśli zakres dostępu się zmieni, polityka powinna zostać zaktualizowana.
